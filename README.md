One funny line, 200 characters or fewer, on any topic — written to make the judge laugh in a single read. My line is a tiny story with a punchline: I finally met my soulmate on a dating app, and we matched instantly on the fact that neither of us was going to message first.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (UTF-8, 1–200 characters).
